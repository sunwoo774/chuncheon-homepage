# 춘천 한일윌로모터펌프 - 파워펌프 서비스센터

춘천시 지역 지하수 모터펌프, 배수펌프, 심정펌프, 압력탱크, 동파, 인버터 낙뢰 피해 출장수리 전문 웹사이트입니다.
가평/홍천/남양주/경기도광주/여주/이천과 색상·레이아웃·서비스 표현 방식을 전부 다르게 제작했습니다.

## 이 사이트만의 차별점

- **톤**: 틸(teal)+피치(peach) 파스텔 조합, 연한 블루그레이 배경. "호수의 도시" 오가닉 웨이브 컨셉.
  (가평=네이비/골드·글래스, 홍천=딥그린/코랄·세리프, 남양주=차콜/오렌지·모노스페이스, 광주=코발트/테라코타·벤토그리드, 여주=버건디/골드·에디토리얼, 이천=모노크롬/레드·갤러리)
- **헤더**: 둥둥 떠 있는 필(pill) 형태의 플로팅 내비게이션 바 — 기존 5개 사이트의 풀와이드 고정 헤더와 전혀 다른 구조.
- **히어로**: 배경에 블롭(blob) 모양 그라데이션 도형 + 하단 물결(wave) 곡선 디바이더로 호수 도시 이미지를 표현. 일러스트 대신 유기적 도형만 사용.
- **서비스 표현**: 카드·타임라인·아코디언·목차형·그리드타일이 아닌 "지그재그(zigzag)" 레이아웃 — 블롭 모양 아이콘 패널과 텍스트가 좌우로 번갈아 배치됩니다.
- **증상 안내**: 가로로 스크롤하는 조약돌(pebble) 모양 카드 리스트.
- **출장권역**: 매장 소재지(양평) 강조 없이 춘천 자체 권역(후평·석사·퇴계동, 신북읍·동면 등)을 둥근 필 리스트로 정직하게 안내.
- **모서리**: 전체적으로 큰 라운드/블롭 형태를 사용해 부드럽고 유기적인 느낌을 강조 (이천의 무각 스타일과 정반대).
